```bash
cd ton618-bot
npm run generate:keys
# Saves to .env.production-generated
# 📌 Backup these keys in password manager!
```

### Step 2: Configure (5 minutes)
```bash
# Copy keys to hosting platform secrets:
# - Square Cloud: Settings → Environment Variables

```

### Step 3: Validate (1 minute)
```bash

# Expected: ✅ ALL CHECKS PASSED
```

### Step 4: Deploy (5 minutes)
```bash

```

```bash
npm run health:check
# Expected: ✅ Bot Health, ✅ Bot Ready State
```
